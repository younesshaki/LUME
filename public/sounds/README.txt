LUME Sound Files

Drop .mp3 / .wav / .ogg / .webm files into the matching subfolders.
The sound library lives at: src/lib/sound/sounds.ts
The action registry lives at: src/lib/sound/actions.ts

Subfolders:
  ui/       — shared UI primitives (clicks, hovers, tab-switch)
  chat/     — chatbot sounds (send, receive, copy)
  product/  — product card sounds (reveal, hover)
  nav/      — page-transition sounds
  showcase/ — cinematic showcase sounds (enter, ambient)
