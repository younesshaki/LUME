# LUME Showcase Notes

This folder is reserved for neutral brand and product notes.

Do not store personal source material, private relationship notes, secrets, or
production credentials in this repository.

Suggested structure:

- `brand.md` for brand positioning and voice.
- `product.md` for product facts, features, and proof points.
- `scenes.md` for the cinematic sequence outline.
- `launch.md` for deployment and QA notes.
