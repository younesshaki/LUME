# Characters: How Git Works

## Dev (the protagonist)
- Role: A software developer learning Git
- Appearance: Young developer with glasses, casual hoodie, curious expression
- Personality: Enthusiastic, slightly confused at first, gradually becomes confident
- Hair: Short, dark hair
- Outfit: Blue hoodie, jeans, sneakers
- Props: Laptop, coffee mug

## Git Mascot (the guide)
- Role: A friendly anthropomorphic commit box (a small cube character)
- Appearance: A floating cube with a Git logo face, arms, and legs
- Personality: Patient, knowledgeable, uses visual demonstrations
- Color: Bright orange/red (like Git branding)
- Props: Mini flag with commit hash, glowing snapshot camera
