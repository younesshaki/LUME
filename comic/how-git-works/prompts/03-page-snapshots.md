# Page 2 — "Snapshots: Repositories & Commits"

## Prompt
Manga-style comic page, 3 panels. Warm neutral tones. Panel 1: The small orange/red Git mascot cube holds a retro "snapshot camera" — each click produces a glowing commit box with a hash label (a1b2c3d). Panel 2: The young developer in a blue hoodie clicks the camera. A commit box materializes labeled "a1b2c3d". Behind them, the working directory is shown as a cozy room where code floats on the walls. Panel 3: A chain of commit boxes connected in a line representing the timeline. The Git mascot explains "Each commit is a full snapshot, not just the differences" in a speech bubble. Clean white backgrounds, manga style.

## Characters
- **Dev**: Young developer, glasses, blue hoodie, engaged expression
- **Git Mascot**: Small orange/red floating cube with snapshot camera prop
- **Setting**: Working directory room → commit timeline

## Style
- Art: manga
- Tone: neutral
- Layout: standard (3 panels)
- Aspect: portrait (3:4)
