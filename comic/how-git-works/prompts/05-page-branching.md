# Page 4 — "Branching Out"

## Prompt
Manga-style comic page, 3 panels. Warm orange tones. Panel 1: A horizontal timeline (main branch) stretches across the page with commit boxes. The Git mascot cube stands at a fork in the road, pointing. Panel 2: The young developer in a blue hoodie walks down a diverging path labeled "feature-x" with a speech bubble "git branch feature-x". The path splits away from the main timeline which continues straight. Panel 3: Both paths grow in parallel — the developer works on the feature path adding new commits, while the main path continues separately with its own commit boxes. Clean backgrounds, manga style showing parallel timelines.

## Characters
- **Dev**: Young developer, glasses, blue hoodie, determined walking pose
- **Git Mascot**: Small orange/red floating cube, at the fork, pointing
- **Setting**: Branching road/timeline landscape

## Style
- Art: manga
- Tone: neutral
- Layout: standard (3 panels)
- Aspect: portrait (3:4)
