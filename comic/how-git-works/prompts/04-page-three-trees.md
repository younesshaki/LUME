# Page 3 — "The Three Trees"

## Prompt
Manga-style comic page, 3 panels. Warm orange and neutral tones. Panel 1: Three labeled rooms side by side — Working Directory (messy desk with scattered papers), Staging Area (a clean organized table), Repository (shelves of labeled books/boxes). Panel 2: The young developer in a blue hoodie writes code at the Working Directory desk. The Git mascot cube gestures and says "git add" — glowing file icons float from the desk to the organized Staging Area table. Panel 3: Developer gestures and says "git commit" — the staged items from the table fly to the Repository shelves where each gets a glowing label (commit hash). Clean manga art style.

## Characters
- **Dev**: Young developer, glasses, blue hoodie, learning expression
- **Git Mascot**: Small orange/red floating cube, pointing/gesturing
- **Setting**: Three distinct rooms — messy desk, organized table, library shelves

## Style
- Art: manga
- Tone: neutral
- Layout: standard (3 panels)
- Aspect: portrait (3:4)
